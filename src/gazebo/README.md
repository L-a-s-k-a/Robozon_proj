# Модель конвейера с использованием TrackController и TrackedVehicle (conveyor.sdf)
## Системные требования
Для корректной работы плагинов необходимо использование ```DART``` версии не ниже 6.13. Версия поставляется с ```Gazebo Harmonic```.
## Прымые сегменты
Для работы прямых сегментов конвейера необходимо использовать плагин ```gz::sim::systems::TrackController```. Чтобы плагин мог имитировать конвейер модель должна быть статична. Скорость конвейера управляется посредством топика ```/track_cmd_vel```. Направление движения конвейера - вдоль оси OX детали, к которой привязан плагин.

*Примечание:* При тесте плагина с более ранней версией движка ```DART``` топик ```track_cmd_center_of_rotation``` не появлялся в топиках gazebo. В новой версии появляется, возможно обойтись без ```TrackedVehicle```

## Поворотные сегменты
Для  организации поворотной секции используется плагин ```gz::sim::systems::TrackedVehicle```. Для своей работы плагин требует минимум 1 левого ```TrackController``` и одного правого. Поворот осуществляется по одной секции - основной - посредством задания мгновенного центра скоростей в топике ```/track_cmd_center_of_rotation``` основной секции. Вторая секция является побочной и не используется на текущий момент. Визуально можно ее скрыть. 

*Примечание:* Вляение расположения побочной секции на работу основной не изучалось. 

## Управление
Для того чтобы запустить сукцеии необходимо опубликовать в топики газебо скорости секций и мгновенный центр скоростей. Например:
```bash
gz topic -t "/model/conveyor/link/right_conv/track_cmd_vel" -m gz.msgs.Double -p "data: 0.3"
gz topic -t "/model/conveyor/link/fwd_conv/track_cmd_vel" -m gz.msgs.Double -p "data: 0.3"
gz topic -t "/model/conveyor/link/rot_conv/track_cmd_vel" -m gz.msgs.Double -p "data: 0.3"
gz topic -t "/model/conveyor/link/rot_conv/track_cmd_center_of_rotation" -m gz.msgs.Vector3d -p "x:1.5, y:-0.25, z:0"
```
